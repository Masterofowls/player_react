
# Проект `player`: музыкальный плеер

**Цель:** приложение, которое загружает песни из базы данных, играет их и позволяет управлять проигрыванием, плейлистами, лайками и поиском.

**Стек:** Vite + React (клиент), Express (сервер), PostgreSQL в Supabase (база данных), Render (деплой).

**CSS** пишется в самом конце.

## Мои частые ошибки (проверять перед запуском)

| Ошибка                                                                                                                                   | Проверка                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Имя в объявлении и в использовании не совпадает (`item` и `items`, `setNewText` и `setText`) | Двойной клик по имени: подсветятся все места                                                        |
| Забытый импорт (`useState`, `useEffect`)                                                                                      | Посмотреть на первую строку файла                                                                           |
| `onClick={f()}` вместо `onClick={f}`                                                                                                 | В `onClick` нет скобок после имени. Если нужен аргумент: `() => f(id)`                          |
| `e.preventDefault` без скобок                                                                                                       | Скобки нужны: `e.preventDefault()`                                                                                          |
| Значение вместо функции и наоборот (`setOpen ? ...`)                                                           | Читаю: первое имя из пары. Меняю: `set...`                                                                    |
| Строка без кавычек (`red`)                                                                                                   | Текст всегда в кавычках                                                                                              |
| Параметр вне своей функции (`fruit` вне `map`)                                                                   | Имя живёт только между скобками стрелки                                                                |
| Проверка на пустоту стоит после действия                                                                    | Проверки и ранние `return` идут в начале функции                                                      |
| `:` и `,` перепутаны                                                                                                            | Двоеточие только внутри `{ }` у объекта. Аргументы и элементы через запятую |
| Скобки в `map`                                                                                                                        | `map((x) => ( ... ))`: сколько открыл, столько закрой                                                        |
| Тег не закрыт (`<input>`)                                                                                                         | Теги без содержимого закрываются так: `<input />`                                                      |
| Форма данных не совпадает с кодом (`{fruit}` вместо `{fruit.name}`)                                      | Элемент это объект: показываю поле                                                                          |
| `try / catch` прячет мои ошибки                                                                                               | В `catch` на время отладки писать `console.log(err)`                                                            |

## Памятка по шаблонам

**Состояние:** `const [name, setName] = useState(начало);` Начало: текст `""`, число `0`, да/нет `false`, список `[]`.

**Список:** `{items.map((item) => (<li key={item.id}>{item.name}</li>))}`

**Удаление:** `setItems(items.filter((item) => item.id !== id));`

**Добавление:** `setItems([...items, newItem]);`

**Изменение одного элемента:** `setItems(items.map((item) => item.id === id ? { ...item, done: !item.done } : item));`

**Загрузка данных:** три состояния (`data`, `loading`, `error`), `useEffect` с `[]`, `async`-функция внутри с вызовом, `try / catch / finally`, два ранних `return`.

**Очистка эффекта:** `const id = setInterval(...); return () => clearInterval(id);`
